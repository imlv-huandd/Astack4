# 自動体験版とOSDCライセンスの同梱

関連: [#6719](https://developer.astack.jp/redmine/issues/6719)、[v3署名契約](../contracts/license-v3.md)、[ライセンス仕様](licensing.md)。

## 利用区分

| 区分 | Astackの条件 | OSDC正式ファイル |
| --- | --- | --- |
| 自動体験版 | 初回インストールから30日、Lite相当 | 添付しない |
| フルトライアル | 発行時指定、既定は日本時間の翌月末、フルオプション・無制限 | OS/バージョン別に選択して添付 |
| 正式購入版 | 契約の期限・オプション・利用枠 | ACP契約時に対象ファイルを選択して添付 |

Liteの現在の販売マスターは全文検索・AI検索、プロジェクト1・ライブラリ2・文書1,000。自動体験版の初期policyはこの値を使用する。日数・権利・枠は `backend/src/main/resources/license/automatic-trial.json` に分離し、将来の配布版で変更できる。発行システムのLiteマスター変更は、オフライン製品へ自動配信されない。

## 初回日時と再インストール

インストーラーはライセンス保存先の `installed-at` にUTC秒精度の初回日時を一度だけ記録する。記録がない手動導入は初回起動時に記録する。自動体験の期限は開始から30×24時間後を排他的終了とする。

製品は日時・期限・権利・枠・インストールIDを `automatic-trial.json` に保存する。再起動やpolicy更新で再計算せず、破損記録を新しい体験期間で置き換えない。署名付きライセンスを優先し、期限切れ・不正ライセンスから体験版に戻して延長しない。

[#6809](https://developer.astack.jp/redmine/issues/6809) の端末紐付けでは、正式ファイルの新規登録用IDを現在のホスト名・対象IPv4・初回日時から導出する。自動体験の保存記録は従来のIDと開始・終了日時の照合を維持し、画面の発行依頼IDと保存済み体験記録のIDは同じとは限らない。ホスト名/IPの変更や正式ライセンスの再発行で、体験期間・権利・枠を再生成しない。旧体験の開始記録から初回日時を復元する際も、既存の期限を延長しない。

新方式IDを保つ復元は、ライセンス保存先一式と、同じOS認識ホスト名・認証対象IPv4の集合が条件となる。DHCPのIPv4も対象のため、保存データだけの復元では同じIDを保証しない。詳しい選別・旧正式ライセンスの移行条件は [端末に紐付くインストールID](licensing.md#端末に紐付くインストールid) を参照する。

Windowsは `%ProgramData%\Astack\license` を使い、サービスと手動起動スクリプトへ `ASTACK_LICENSE_DIRECTORY` を設定する。SYSTEM・管理者に更新権限を与える。通常アンインストールはアプリ配置先だけを削除し、この記録を残す。旧 `app\data\license` / `data\license` からの初回移行はサービス停止後にコピーし、競合ファイルを上書きしない。独自のサービスアカウントにはアクセス権を付与する。手動起動のrun.batは管理者として実行し、非昇格なら起動前に案内して停止する。OSDC用の環境変数はReadMeにある製品版から決め、V12.0ならSBC120_HOME/LIC_PATH/DMC_TBLPATHを設定する。

Linux手動導入では `/var/lib/astack/license` など別の永続領域を用意し、サービスの `ASTACK_LICENSE_DIRECTORY` に指定する。既存ID・ライセンス・体験記録は一式でバックアップ・復元し、更新時に削除しない。VM復元・全記録削除の完全防止やオンライン認証は追加しない。

## OSDC管理と配置

管理者はOS（Windows/Linux）・製品バージョン・表示名・ファイル・有効状態を管理する。内容は版ごとに保存する。発行担当者はACP選択時に同梱対象を選ぶ。未選択なら正式ファイルを添付しない。変更と発行時に版番号の競合を確認する。過去の発行物はマスター更新後も同じ内容を再ダウンロードできる。

`ASTACK_LICENSE_OSDC_DIRECTORY` はOSDCライセンス配置先。Windowsはインストール先のOSDCフォルダ、Linux既定は `/opt/astack/converter/etc`。`ASTACK_LICENSE_OSDC_VERSION` を指定するか、配置先または親の `ReadMe.txt` からOSDCバージョンを確認する。未知・不一致のまま添付を配置しない。

OSDCの起動設定と上記配置先は同じインストールを指すようにする。現行Linux `run.sh` の `SBC120_LIC_PATH` は `/opt/astack/converter/etc`。独自構成でもOSDC側の探索先と合わせる。

署名・安全な配置・失敗時の復旧はv3契約を参照。実ファイルはGit・画面・一覧API・監査ログへ出さない。DBとバックアップへのアクセスを制限する。発行済みダウンロードファイルにはOSDCライセンス内容が含まれる。

## 評価終了と利用条件

期限後は新規ビルド・更新・ACP変換を停止し、既存公開文書の閲覧・ダウンロードを継続する。フルトライアル同梱のOSDC正式ファイルは無期限だが、利用条件で次を案内する。

- Astackを通じた評価目的に限り利用する。
- OSDC単独利用・他システム転用・ライセンスファイル再配布を禁止する。
- 評価終了後は利用を停止し、同梱ファイルを削除する。

OSDC単体のコピーを技術的に完全防止する機能は追加しない。元から配置された別契約のファイルを、期限だけで一律削除しない。
