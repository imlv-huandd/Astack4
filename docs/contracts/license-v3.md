# ライセンスファイル v3：OSDCライセンスの同梱

新規の製品バージョン指定発行は [v4契約](license-v4.md) を参照。本書のv3は既存ファイルの互換契約として維持する。

関連: [#6719](https://developer.astack.jp/redmine/issues/6719)、[v2契約](license-v2.md)、[製品ライセンス仕様](../specs/licensing.md)。

## 署名と互換性

OSDCファイルを添付する発行にv3を使用し、添付しない発行はv2を維持する。製品はv1/v2/v3を検証する。既存ファイルの署名や権利を変更しない。ファイル上限は64KiB、文字列・JSON・日時・上限・機能の検証はv2を継承する。

envelopeは `version`（整数3）・`keyId`・`payload`・`signature` の4項目だけ。Ed25519の署名対象はUTF-8の `ASTACK-LICENSE-V3\n{keyId}\n{payload}`。payloadはv2の10項目と、次の `osdcLicense` オブジェクトの計11項目だけを持つ。添付がある場合は `features` に `CONVERTER_PLUGIN` が必要。

| 項目 | 条件 |
| --- | --- |
| `id` | 発行システムのOSDCマスターID、小文字の標準UUID |
| `version` | 選択時のマスター版、正整数 |
| `os` | `WINDOWS` または `LINUX` |
| `productVersion` | 対象OSDCの製品バージョン。例: `11.1`、`12.0` |
| `fileName` | `sbcnlic.dat` 固定。パスとして解釈しない |
| `sha256` | 復元したファイルのSHA-256、小文字16進64桁 |
| `data` | 元ファイル1〜16,384バイトの正規base64url、パディングなし |

署名対象にファイル内容・OS・バージョン・ハッシュをすべて含める。署名、UUID、未知/重複項目、復号サイズ、ハッシュ、ACP権利の不正を拒否する。署名は改ざん検知であり、内容の秘匿・OSDC単独利用の技術的な制限ではない。

## 発行・履歴

OSDCマスターの一覧・監査・発行履歴・製品状態APIはファイルの生データを返さない。発行時にID・版番号・現在の有効状態を同じトランザクションで確認し、無効化・競合を拒否する。署名済みファイルにはその時点のバイト列を保存し、マスター差替えや停止後も再ダウンロードは同じファイルを返す。同一要求の成功済み再送を現在のマスターで再生成しない。

OSDCの添付は、正式購入版とフルトライアル版で利用する。インストール直後の自動体験版には正式ファイルを添付しない。OSDC評価版の構成を維持し、ファイル削除で評価期限を延長しない。

## 製品への配置

製品は署名・インストールID・期限・ACP権利を検証したうえで、実行環境のOS・OSDCバージョンと一致することを確認する。配置先はホストの管理設定・インストール構成で決め、ライセンスから任意の保存パスを受け取らない。不一致・検出不能・書込み不可なら、登録前のライセンスとOSDCファイルを保持してエラーを返す。

登録途中の障害に備えて既存ファイルを退避し、署名済みライセンス・OSDCファイル・監査の確定/復旧を照合する。プレビューでOSDCファイルを書き換えない。OSDCファイル内容をログやAPIへ出さない。期限切れ後はAstack経由の新規処理を停止する。無期限のOSDCファイル自体の期限を変更する処理は行わない。

## フルトライアルの利用条件

フルトライアルに同梱するOSDCライセンスは無期限の正式ファイルだが、利用はAstackを通じた評価目的に限る。OSDCの単独利用、他システムへの転用、ライセンスファイルの再配布を禁止し、評価終了後は利用停止・同梱ファイルの削除を求める。この条件を発行・登録時に案内する。VM復元やOS管理者によるファイル複製を技術的に完全防止する仕組みは追加しない。
